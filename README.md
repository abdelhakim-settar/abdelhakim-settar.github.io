# Abdelhakim Settar — personal academic website

Bilingual French/English static site hosted with GitHub Pages.

## Automatic bibliometrics
Home and Publications query OpenAlex author A5042702773 on each visit. The response must match ORCID 0000-0002-2147-880X. A dated embedded snapshot and optional browser-local cache preserve the last available values if the API is unavailable. No account, key or subscription is required. Google Scholar is linked separately; its counters are not copied or automatically scraped.

## Editorial updates
The Publications list merges the verified author bibliography with HAL and OpenAlex on each visit. DOI/title matching removes duplicates; SSRN preprints are excluded, proceedings are classified as conference contributions, and corrections remain linked to their original articles without double counting. The list, filters, contribution chart and CSV export share the same data. Projects, profile, teaching, collaborations, thematic percentages and supervision records remain editorial. CV downloads are supplied by the author.

## SDG assets
Official United Nations SDG icons, used unchanged. Sources: https://www.un.org/sustainabledevelopment/news/communications-material/ . Usage guidelines are included as sdg-guidelines.pdf. Context and required attribution appear next to the icons in French and English.

## Institutional and journal marks
Institutional logos are sourced from univ-orleans.fr and insa-centrevaldeloire.fr. Journal mastheads and publisher marks are sourced from MDPI, Wiley, Elsevier and AIP Publishing official pages. They identify affiliations, publication venues and editorial roles, and link to the corresponding institution or journal. The AIP mark identifies the publisher of AIP Conference Proceedings.

## Scientific presentation and bibliography
The scientific presentation covers thermochemical phenomena, chemical kinetics and coupled transport, with experiments and numerical modelling. Scientific figures link directly to coauthored publications through their DOI. The author's overview diagrams have French and English versions. Collaborations identify laboratories, universities, cities and countries using institutional links. The portrait was provided through the author's LinkedIn profile with his authorization.

The initial verified bibliography contains 70 references, including 47 distinct journal articles, as of 16 November 2026. Later records are added from public indexes. JITH book chapters use COS; AIP Conference Proceedings contributions use ACTI. Source-specific bibliometric totals remain separate from the classified bibliography.
